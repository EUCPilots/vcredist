# Update-VcMdtBundle

## SYNOPSIS
Actualiza conjuntos de aplicaciones de Redistribuibles de Visual C++ en un recurso compartido de Microsoft Deployment Toolkit.

## SYNTAX

```
Update-VcMdtBundle [-MdtPath] <String> [-AppFolder <String>] [[-MdtDrive] <String>] [[-Publisher] <String>]
 [[-BundleName] <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Después de importar o agregar aplicaciones de Redistribuibles de Visual C++ a un recurso compartido de Microsoft Deployment Toolkit, se puede actualizar un conjunto de aplicaciones existente con los GUID de las nuevas aplicaciones de Redistribuibles de Visual C++.

El conjunto se actualizará en el recurso compartido de implementación de MDT con propiedades predeterminadas similares a las siguientes:

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables.
Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version:2021-Mar-18 Publisher: Microsoft Language: en-US Dependencies: (VcRedists in the MDT share)

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist
Update-VcMdtApplication -VcList (Get-VcList) -Path C:\Temp\VcRedist -MdtPath \\server\deployment
Update-VcMdtBundle -MdtPath \\server\deployment
```

Descripción: Obtiene la lista de Redistribuibles de Visual C++, los descarga en C:\Temp\VcRedist y actualiza cada redistribuible en el recurso compartido de implementación de MDT ubicado en \server\deployment.
