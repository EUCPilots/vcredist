# Import-VcConfigMgrApplication

## SYNOPSIS
Crea aplicaciones de Redistribuibles de Visual C++ en un sitio de ConfigMgr.

## SYNTAX

```
Import-VcConfigMgrApplication [-VcList] <PSObject> [-Path <String>] [-CMPath] <String> [-SMSSiteCode] <String>
 [[-AppFolder] <String>] [-Silent] [-NoCopy] [[-Publisher] <String>] [[-Keyword] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Crea una aplicación en un sitio de Configuration Manager para cada Redistribuible de Visual C++ e incluye la configuración para determinar si el redistribuible puede ejecutarse en Windows de 32 o 64 bits, así como la clave Uninstall para detectar si está instalado.
Cada tipo de implementación recibe un requisito de arquitectura basado en SupportedArchitecture. La función crea o reutiliza una condición global de script del sitio que detecta la arquitectura nativa de Windows en los dispositivos de destino.

Usa Get-VcList y Save-VcRedist para descargar el redistribuible y crear la matriz de redistribuibles que se importará en ConfigMgr.

Las aplicaciones se importarán en ConfigMgr con propiedades predeterminadas similares a las siguientes:

Deployment type: Name: SCRIPT_Visual C++ Redistributable for Visual Studio 2019 Technology: Script Installer Administrator comments: Generated by Import-VcConfigMgrApplication Content location: \configmgr\Applications\VcRedists\2019\14.28.29913.0\x86\ Installation program: VC_redist.x86.exe /install /quiet /norestart Uninstall program: "%ProgramData%\Package Cache\{03d1453c-7d5c-479c-afea-8482f406e036}\VC_redist.x86.exe" /uninstall /quiet /noreboot Detection method: (Registry path)

## EXAMPLES

### EXAMPLE 1
```
$VcList = Get-VcList | Save-VcRedist -Path "C:\Temp\VcRedist"
Import-VcConfigMgrApplication -VcList $VcList -CMPath "\\server\share\VcRedist" -SMSSiteCode LAB
```

Descripción: Descarga los Redistribuibles de Visual C++ compatibles en "C:\Temp\VcRedist", los copia en "\server\share\VcRedist" y los importa como aplicaciones en el sitio LAB de ConfigMgr.
