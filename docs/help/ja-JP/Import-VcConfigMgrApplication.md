# Import-VcConfigMgrApplication

## SYNOPSIS
ConfigMgr サイトに Visual C++ Redistributable アプリケーションを作成します。

## SYNTAX

```
Import-VcConfigMgrApplication [-VcList] <PSObject> [-Path <String>] [-CMPath] <String> [-SMSSiteCode] <String>
 [[-AppFolder] <String>] [-Silent] [-NoCopy] [[-Publisher] <String>] [[-Keyword] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
各 Visual C++ Redistributable について Configuration Manager サイトにアプリケーションを作成し、Redistributable を 32 ビットまたは 64 ビット Windows のどちらで実行できるか、およびインストール状態の検出に使用するアンインストール キーを設定します。
各展開の種類には SupportedArchitecture に基づくアーキテクチャ要件が設定されます。この関数は、対象デバイスのネイティブ Windows アーキテクチャを検出するサイト全体のスクリプト グローバル条件を作成または再利用します。

Get-VcList と Save-VcRedist を使用して Redistributable をダウンロードし、ConfigMgr にインポートする Redistributable の配列を作成します。

アプリケーションは、次のような既定のプロパティで ConfigMgr にインポートされます。

## EXAMPLES

### EXAMPLE 1
```
$VcList = Get-VcList | Save-VcRedist -Path "C:\Temp\VcRedist"
Import-VcConfigMgrApplication -VcList $VcList -CMPath "\\server\share\VcRedist" -SMSSiteCode LAB
```

説明: サポート対象の Visual C++ Redistributable を "C:\Temp\VcRedist" にダウンロードし、"\server\share\VcRedist" にコピーして、ConfigMgr サイト LAB にアプリケーションとしてインポートします。
