# New-VcMdtBundle

## SYNOPSIS
インポート済みの Visual C++ Redistributable アプリケーション向けに、MDT アプリケーション バンドルを作成または置換します。

## SYNTAX

```
New-VcMdtBundle [-MdtPath] <String> [[-AppFolder] <String>] [-Force] [[-MdtDrive] <String>]
 [[-Publisher] <String>] [[-BundleName] <String>] [[-Language] <String>] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
選択したアプリケーション フォルダーにある既存の Visual C++ Redistributable アプリケーションをバージョン順に並べ、依存関係とする MDT バンドルを作成します。

最初に Import-VcMdtApplication でアプリケーションをインポートしてください。-Force を指定すると既存のバンドルを置換し、置換に失敗した場合は以前のバンドルを復元します。Windows PowerShell 5.1 と Microsoft Deployment Toolkit モジュールが必要です。

Microsoft が MDT をサポートしなくなったため、この関数は非推奨です。呼び出すと警告が表示され、今後の VcRedist リリースで削除される可能性があります。

バンドルは、次のような既定のプロパティで MDT 展開共有にインポートされます。

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables.
Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version: (current culture's short date format) Publisher: Microsoft Language: en-US Dependencies: imported Visual C++ Redistributable applications

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist | Import-VcMdtApplication -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment
```

説明: Visual C++ Redistributable の一覧を取得し、C:\Temp\VcRedist にダウンロードして、各 Redistributable を \server\deployment の MDT 展開共有にインポートします。

### EXAMPLE 2
```
$VcList = Get-VcList -Export All | Save-VcRedist -Path C:\Temp\VcRedist
Import-VcMdtApplication -VcList $VcList -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment -Force
```

説明: サポート対象および対象外の Visual C++ Redistributable の一覧を変数 $VcList に取得し、C:\Temp\VcRedist にダウンロードします。各 Redistributable を \server\deployment の MDT 展開共有にインポートし、アプリケーション バンドルを作成します。
