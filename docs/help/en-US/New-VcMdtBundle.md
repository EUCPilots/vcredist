# New-VcMdtBundle

## SYNOPSIS
Creates or replaces an MDT application bundle for imported Visual C++ Redistributable applications.

## SYNTAX

```
New-VcMdtBundle [-MdtPath] <String> [[-AppFolder] <String>] [-Force] [[-MdtDrive] <String>]
 [[-Publisher] <String>] [[-BundleName] <String>] [[-Language] <String>] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Creates an MDT bundle whose dependencies are the existing Visual C++ Redistributable applications in the selected application folder, ordered by version.

Import applications first with Import-VcMdtApplication. Use -Force to replace an existing bundle. If replacement fails, the previous bundle is restored. The function requires Windows PowerShell 5.1 and the Microsoft Deployment Toolkit module.

This function is deprecated because Microsoft no longer supports MDT. It emits a warning and may be removed in a future release of VcRedist.

The bundle will be imported into the MDT Deployment share with the default properties similar to the following:

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables. Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version: (current date in the current culture's short date format) Publisher: Microsoft Language: en-US Dependencies: imported Visual C++ Redistributable applications

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist | Import-VcMdtApplication -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment
```

Description: Downloads and imports the default supported Redistributables, then creates a bundle that depends on the imported applications.

### EXAMPLE 2
```
$VcList = Get-VcList -Export All | Save-VcRedist -Path C:\Temp\VcRedist
Import-VcMdtApplication -VcList $VcList -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment -Force
```

Description: Imports all manifest entries and creates or replaces the bundle in the MDT deployment share.
