# Update-VcMdtBundle

## SYNOPSIS
Updates Visual C++ Redistributable application bundles in a Microsoft Deployment Toolkit share.

## SYNTAX

```
Update-VcMdtBundle [-MdtPath] <String> [-AppFolder <String>] [[-MdtDrive] <String>] [[-Publisher] <String>]
 [[-BundleName] <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
After importing or adding Visual C++ Redistributable applications in a Microsoft Deployment Toolkit share, an existing application bundle can be updated with GUIDs for the new Visual C++ Redistributable applications.
This function updates dependencies and the bundle version; it does not import applications. It requires Windows PowerShell 5.1 and the Microsoft Deployment Toolkit module.

This function is deprecated because Microsoft no longer supports MDT. It emits a warning and may be removed in a future release of VcRedist.

The bundle will be updated into the MDT Deployment share with the default properties similar to the following:

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables.
Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version: (current date in the current culture's short date format) Publisher: Microsoft Language: en-US Dependencies: imported Visual C++ Redistributable applications

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist |
    Import-VcMdtApplication -MdtPath \\server\deployment
Update-VcMdtBundle -MdtPath \\server\deployment
```

Description: Imports the default supported Redistributables and updates the existing bundle's dependencies to include the imported applications.
