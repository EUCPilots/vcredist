# New-VcMdtBundle

## SYNOPSIS
Erstellt oder ersetzt ein MDT-Anwendungspaket für importierte Visual C++ Redistributable-Anwendungen.

## SYNTAX

```
New-VcMdtBundle [-MdtPath] <String> [[-AppFolder] <String>] [-Force] [[-MdtDrive] <String>]
 [[-Publisher] <String>] [[-BundleName] <String>] [[-Language] <String>] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Erstellt ein MDT-Anwendungspaket mit Abhängigkeiten zu den vorhandenen Visual C++ Redistributable-Anwendungen im ausgewählten Anwendungsordner, sortiert nach Version.

Importieren Sie die Anwendungen zuerst mit Import-VcMdtApplication. Mit -Force wird ein vorhandenes Paket ersetzt; bei einem Fehler wird das vorherige Paket wiederhergestellt. Erforderlich sind Windows PowerShell 5.1 und das Microsoft Deployment Toolkit-Modul.

Diese Funktion ist veraltet, da Microsoft MDT nicht mehr unterstützt. Sie gibt eine Warnung aus und kann in einer zukünftigen VcRedist-Version entfernt werden.

Das Paket wird mit den folgenden oder ähnlichen Standardeigenschaften in die MDT-Bereitstellungsfreigabe importiert:

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables.
Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version: (current culture's short date format) Publisher: Microsoft Language: en-US Dependencies: imported Visual C++ Redistributable applications

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist | Import-VcMdtApplication -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment
```

Description: Ruft die Liste der Visual C++ Redistributables ab, lädt sie nach C:\Temp\VcRedist herunter und importiert jedes Redistributable in die MDT-Bereitstellungsfreigabe unter \server\deployment.

### EXAMPLE 2
```
$VcList = Get-VcList -Export All | Save-VcRedist -Path C:\Temp\VcRedist
Import-VcMdtApplication -VcList $VcList -MdtPath \\server\deployment
New-VcMdtBundle -MdtPath \\server\deployment -Force
```

Description: Ruft die Liste der unterstützten und nicht unterstützten Visual C++ Redistributables in der Variablen $VcList ab, lädt sie nach C:\Temp\VcRedist herunter, importiert jedes Redistributable in die MDT-Bereitstellungsfreigabe unter \server\deployment und erstellt ein Anwendungspaket.
