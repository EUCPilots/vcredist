# Import-VcConfigMgrApplication

## SYNOPSIS
Erstellt Anwendungen für Visual C++ Redistributables an einem ConfigMgr-Standort.

## SYNTAX

```
Import-VcConfigMgrApplication [-VcList] <PSObject> [-Path <String>] [-CMPath] <String> [-SMSSiteCode] <String>
 [[-AppFolder] <String>] [-Silent] [-NoCopy] [[-Publisher] <String>] [[-Keyword] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Erstellt für jedes Visual C++ Redistributable eine Anwendung an einem Configuration-Manager-Standort. Dabei wird festgelegt, ob das Redistributable unter 32-Bit- oder 64-Bit-Windows ausgeführt werden kann, sowie der Deinstallationsschlüssel zur Erkennung einer vorhandenen Installation.
Jeder Bereitstellungstyp erhält eine Architekturanforderung auf Grundlage von SupportedArchitecture. Die Funktion erstellt standortweit eine globale Skriptbedingung zur Erkennung der nativen Windows-Architektur auf Zielgeräten oder verwendet eine bereits vorhandene.

Verwenden Sie Get-VcList und Save-VcRedist, um das Redistributable herunterzuladen und das Array der Redistributables für den Import in ConfigMgr zu erstellen.

Die Anwendungen werden mit den folgenden oder ähnlichen Standardeigenschaften in ConfigMgr importiert:

## EXAMPLES

### EXAMPLE 1
```
$VcList = Get-VcList | Save-VcRedist -Path "C:\Temp\VcRedist"
Import-VcConfigMgrApplication -VcList $VcList -CMPath "\\server\share\VcRedist" -SMSSiteCode LAB
```

Description: Lädt die unterstützten Visual C++ Redistributables nach "C:\Temp\VcRedist" herunter, kopiert sie nach "\server\share\VcRedist" und importiert sie als Anwendungen in den ConfigMgr-Standort LAB.
