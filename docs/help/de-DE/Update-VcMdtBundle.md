# Update-VcMdtBundle

## SYNOPSIS
Aktualisiert Anwendungspakete für Visual C++ Redistributables in einer Freigabe des Microsoft Deployment Toolkit.

## SYNTAX

```
Update-VcMdtBundle [-MdtPath] <String> [-AppFolder <String>] [[-MdtDrive] <String>] [[-Publisher] <String>]
 [[-BundleName] <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Nachdem Visual-C++-Redistributable-Anwendungen in eine Freigabe des Microsoft Deployment Toolkit importiert oder dort hinzugefügt wurden, kann ein vorhandenes Anwendungspaket mit den GUIDs der neuen Visual-C++-Redistributable-Anwendungen aktualisiert werden.

Das Paket wird mit den folgenden oder ähnlichen Standardeigenschaften in der MDT-Bereitstellungsfreigabe aktualisiert:

Location: Applications\VcRedists Name: Microsoft Visual C++ Redistributables Comments: Application bundle for installing Visual C++ Redistributables.
Generated by New-VcMdtBundle Short name: Visual C++ Redistributables Version:2021-Mar-18 Publisher: Microsoft Language: en-US Dependencies: (VcRedists in the MDT share)

## EXAMPLES

### EXAMPLE 1
```
Get-VcList | Save-VcRedist -Path C:\Temp\VcRedist
Update-VcMdtApplication -VcList (Get-VcList) -Path C:\Temp\VcRedist -MdtPath \\server\deployment
Update-VcMdtBundle -MdtPath \\server\deployment
```

Description: Ruft die Liste der Visual C++ Redistributables ab, lädt sie nach C:\Temp\VcRedist herunter und aktualisiert jedes Redistributable in der MDT-Bereitstellungsfreigabe unter \server\deployment.
